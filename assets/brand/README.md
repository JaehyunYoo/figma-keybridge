# Keybridge 로고

K의 가운데 연결 부분을 강조한 심볼입니다.

- Charcoal: #1C201D
- Lime: #C4F35B
- Ivory: #F4F5EF

`keybridge-icon.svg`는 컬러 벡터 원본입니다. `keybridge-mark-mono.svg`는 배경이 없는 단색 심볼입니다.

PNG는 128, 256, 512, 1024px 크기로 제공합니다. Figma 플러그인 배포 아이콘에는 128px 파일을 사용할 수 있습니다. 플러그인 내부 헤더에는 동일한 벡터 심볼을 적용했습니다. Figma 검색 목록의 아이콘은 별도 배포 설정에서 등록해야 합니다.
