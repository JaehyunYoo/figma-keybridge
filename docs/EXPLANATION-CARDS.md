# Figma 기본 주석 (Annotations) — v0.7

이 버전은 텍스트 레이어의 `node.annotations`를 사용합니다. 캔버스에 카드, 말풍선, 선, 텍스트 도형을 만들지 않습니다.

1. 플러그인을 다시 실행하고 텍스트를 불러옵니다.
2. 키와 기록 버전을 입력합니다.
3. **키 저장 시 Figma 기본 주석 생성·갱신** 옵션을 켜고 키를 저장합니다. 옵션은 기본으로 켜져 있습니다.
4. 이미 저장한 키는 **Figma 주석 생성·갱신** 버튼으로 주석만 추가하거나 갱신합니다.
5. 해당 텍스트 레이어를 선택하고 Figma Dev Mode의 주석에서 확인합니다. 실제 표시와 접근은 Figma의 기능·권한 상태에 따릅니다.

주석 예:

```text
키: common.save
문구: 저장하기
기록 버전: 1.1.1
```

별도 Figma 토큰을 입력하지 않습니다. 파일에 플러그인이 관리하는 Keybridge 주석 카테고리를 생성합니다. 기존 주석과 고정한 속성은 유지합니다.

## 갱신과 기존 카드 처리

- 마지막으로 생성한 주석을 노드 메타데이터로 식별하고 해당 주석만 갱신합니다.
- Keybridge 주석을 Figma에서 직접 수정한 경우 자동으로 덮어쓰지 않고 건너뛴 개수를 안내합니다. 직접 수정한 내용은 별도 주석으로 옮긴 뒤 해당 Keybridge 주석을 지우고 다시 갱신할 수 있습니다.
- 번역 대상에서 제외하거나 키를 지운 항목은 변경되지 않은 Keybridge 주석만 제거합니다.
- 예전 v0.5/v0.6 카드가 연결되어 있으면 기본 주석 쓰기가 성공한 뒤에만 숨깁니다. 삭제하지 않으므로 Figma 레이어 목록에서 다시 표시할 수 있습니다. 연결되지 않은 오래된 카드는 자동으로 숨기지 않습니다.
- UI의 저장 옵션을 끄면 키만 저장합니다. 기존 주석은 자동 갱신하지 않습니다.
- 갱신은 현재 불러온 텍스트가 대상입니다. 문구를 Figma에서 수정했다면 다시 불러온 뒤 실행하세요.
- 기본 주석 API가 지원되지 않거나 권한 문제로 실패하면 오류를 표시합니다. 도형 카드로 대체하지 않습니다.

자동 검증은 모의 Figma API와 UI 환경에서 수행했습니다. 실제 사용자 파일에서 기본 주석 표시까지 확인한 상태는 아닙니다.

[Figma Annotation API](https://developers.figma.com/docs/plugins/api/Annotation/)
